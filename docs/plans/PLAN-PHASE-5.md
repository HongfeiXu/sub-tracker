## 需求备注

### 完整扣款历史

- 当前数据已可从各订阅的 `billingHistory` 聚合出历史流水。
- 已观察到 11 条订阅中共有 22 条历史记录，可直接作为历史页数据源。
- 已修复：active 订阅在应用启动和导入时会补齐从 `startDate` 到今天已发生但缺失的扣款记录，并推进 `nextBillDate` 到未来日期。
- 已完成第一版：新增“记录”Tab，按月份分组、日期倒序展示所有扣款记录，并显示每月 CNY / USD 小计。

### 套餐 / 价格变化

- 当前模型把金额、周期、开始日期直接挂在 `Subscription` 上。
- 当同一服务发生价格变化时，例如 Claude Code 从 `$125/month` 变为 `$20/month`，用户只能取消旧条目并新建新条目。
- 这种方式能保留金额差异，但会把同一服务拆成多个卡片，历史和当前订阅的关系不够清楚。
- 待设计方向：在同一个订阅下增加“价格计划历史”或“变更记录”，让当前订阅只显示一张卡片，同时历史记录仍保留不同期间的真实金额。
- 已创建设计文档：`docs/plans/features/FEATURE-003-price-plan-history.md`。
- 实施按四个切片推进：数据模型与迁移、价格历史计费逻辑、编辑交互、记录页与统计适配。
- 已完成第一版：新增 `priceHistory` 模型、旧数据迁移、计费变更选择交互；记录页和年度统计优先按扣款记录自身币种汇总。
